# Torne Mobile Helper

Macで iPad 版の torne mobile を使うときの補助アプリです。ウィンドウを閉じたあとも torne が裏で動いているときに、起動状態を確認して開き直したり、終了したりできます。torne mobile や nasne の代わりになるアプリではありません。

## ダウンロード

ビルド済みのアプリを使う場合は、[Releases](https://github.com/kumakikai/torne-mobile-helper/releases/latest) から `TorneHelper-vX.X.zip` をダウンロードして展開し、`TorneHelper.app` を開いてください。必要ならアプリケーションフォルダに移動してください。

### 初回起動で止められたとき

このアプリはローカル署名のみで、Apple の公証を受けていません。そのため初回起動時に「開発元を確認できない」「開けません」などと表示されることがあります。

1. 表示されたダイアログを閉じます。
2. **システム設定 → プライバシーとセキュリティ** を開き、下の方に表示される TorneHelper の項目で **このまま開く** を選びます。
3. 確認が表示されたら、もう一度 **開く** を選びます。

それでも開けない場合は、ターミナルで次を実行してから開き直してください（パスは実際の置き場所に合わせてください）。

    xattr -dr com.apple.quarantine /Applications/TorneHelper.app

信頼できない場合は、ダウンロード版を使わずに下の手順でソースからビルドしてください。

## ビルド

Apple Silicon Mac と Xcode Command Line Tools が必要です。macOS 27.0.1 でビルドを確認しています。

1. このリポジトリをクローンするか、GitHub の **Code → Download ZIP** から入手して展開します。
2. ターミナルでそのフォルダを開き、以下を実行します。

   ```sh
   ./build.sh
   ```

3. `build/TorneHelper.app` を開きます。必要ならアプリケーションフォルダに移動してください。

ビルドしたアプリはローカル署名で、公証はしていません。先に [torne mobile](https://apps.apple.com/jp/app/torne-mobile/id949323340) をインストールしてください。

## 使い方

| ボタン | 操作 |
| --- | --- |
| 起動状態を更新 | torne の起動状態と PID を表示します。 |
| 再起動して復帰… | torne を終了してから開き直します。再生中なら止まります。 |
| 強制終了… | 裏で動き続けている torne を終了します。終了後にまた開いた場合は、下の欄の案内に沿ってもう一度強制終了してください。 |
| Apple Music同時起動問題の対処 | システム設定を開きます。**プライバシーとセキュリティ → メディアとApple Music → torne mobile** をオフにして試してください。 |

### 購入情報の復旧が進まないとき

**レシートを診断…** から torne mobile の `Data/StoreKit/receipt` を選ぶと、現在のファイル権限と目安を表示します。目安は `0600`（所有者だけが読み書き可）です。たとえば `1130` だと、所有者に読み取り権限がありません。レシートの中身や購入状態は確認しません。

**レシートの権限を修正…** は、torne mobile 本体のレシートを特定できた場合に限り、確認後に権限を `0600` へ変更します。macOS がアクセス許可を求めた場合は、表示された内容を確認してください。対象を特定できない場合は変更しません。対象は見つかっても修正できない場合は、**Finderで開く** から対象フォルダを開けます。

権限の修正だけで購入情報の復旧が直るとは限りません。また、復旧操作でレシートが作り直されると、権限も変わることがあります。
